# 自动创作质量内核调研：人声、低谷与写时配额（V0.101）

> 日期：2026-08-30｜依据：存量宪章 §12、实测推流精读台账、V0.95/V0.100 落地对照、reference/ 外部框架、当前扫描报告
> 目的：把「提高自动创作质量」从返工侧改回写作内核，并给出本轮取舍。

## 结论先行

墨舟近十个版本（V0.100.7–V0.100.16）几乎全部花在推荐返工的状态合同、证据定位、盲审与落盘闸上。这些工作让坏稿更难悄悄覆盖好稿，但**不能提高第一次写出来的正文质量**。自动写作内核上次系统性升级停在 V0.100.0（有界上下文、戏剧契约、叙事投影）。

本轮质量瓶颈不在缺一个 Agent 外壳，而在三件已经写进纪律、却没有按写作粒度落地的事：

1. **章级红线按场景各自写满**——破折号已按场景分预算，动作母题没有；每场景各写两次「蹲」，四场就是八次，扫描里单章 23 次蹲是结构必然，不是模型偶然不听话。
2. **人声只有通用纪律，没有角色级语音卡**——`DIALOGUE_VOICE_TEXT` 要求一人一腔，注入的却是所有人共用的「不要说偈语」；性格列不能代替说话方式。
3. **快感调度只催回报、不派低谷**——连续兑现没有物象代价，爽点边际归零；独立故事碎片（物件当心理温度计）从未进写作指令。

`isHistory` 二元开关仍是题材分叉的唯一入口。本轮用题材偏好槽位接住它（历史=严格物证/权限/中等回报），不一次拆掉全部历史特判。

明确不做：GraphRAG、多 Agent、Prompt Registry 全量拆分、DeepWrite 全量风格克隆（仍留 §12.2）。通用 harness 评估结论（`docs/harness-evaluation-v099.md`）维持。

## 1. 内部实证

实测推流前二次精读（`docs/audits/示例历史长篇-推流前二次精读报告-V0.97.1.md`）把追读损伤收成五类：越权、物证过顺、伪精确、动作母题/段首主语、连续性。本地检测器后来补了物证堆叠、数字报表、母题词表、少年权限。扫描报告 `tmp-demo-review/scan-report-after.txt` 仍显示：短章、蹲/低头/停住破线、顿了顿/一股、对白偈语。说明**检测在章级生效，生成在场景级无余量视野**。

V0.94 已把破折号按场景字数占比切预算，并在写后做确定性压缩。动作母题、高频套话没有走同一条路。这与 V0.100.14「闸必须与改写单元同粒度」是同一条教训的镜像：改写收窄到窗口后不能套章级对话占比；生成切成场景后不能让每场各自吃满章级配额。

角色侧：`personality` 是性格单源（V0.96 已禁止 `card.traits` 双写）。叙事记忆 `voice` 类在结算后提取，属于回看一致性，不是写前约束。配角因此共用导师格言腔——V0.94 纪律已经点名，缺的是每人一张可注入、可检测的说话卡。

快感引擎 `schedulerCheck` 会在连续平路或爽点间隔过大时要求下一章兑现，从未要求连续兑现后必须付代价。心理学上这是 RPE/压抑-释放的另一半（`docs/快感工程调研报告.md`），网文实战叫低谷时刻。

## 3. 框架动作（五件套）

1. **纪律**：`VALLEY_FRAGMENT_TEXT`（低谷用物象，碎片不推进主线机关）；语音卡是结构化字段，不写每章重复的正例句。
2. **槽位**：写作指令加章级余量配额 + 低谷简报（仅约束命中时）；角色卡加说话/禁腔；审校注入同场人物卡。
3. **确定性校验**：母题/套话余量在写时可见；禁腔命中对白则 medium；物证过顺阈值随 `evidenceBound` 收紧或关闭。
4. **台账**：`characters.speech` / `speech_forbid` 新列，roster 只填空；偏好槽在 `settings.craftProfile`，默认由题材预设填充。
5. **测试**：`tests/v1010.test.js` 覆盖配额均分、语音注入、禁腔检测、低谷调度、非历史零误伤。

## 4. 不在本轮的范围

- 不改已发布正文，不跑维护补丁改《实测》稿。
- 不把 `isHistory` 全部替换掉——新路径走 `resolveCraftProfile`，旧历史护栏保持。
- 不加人工审批点；角色库编辑只是已有观察/档案面的字段扩展。
