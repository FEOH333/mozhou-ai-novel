> 调研定位：为《示例历史长篇》架空线（卷5-15）提供"历史人物正式登场"的结构化依据。
> 用途：人物登场窗口（写作/细纲注入）、人物级时代校验（正文时间错位拦截）、朝廷重振因果链（卷纲/书纲朝堂线）。

## 七、朝廷重振因果链（架空分岔后的"包圆"设计）

### 史实前提（不可改的前因）
贾似道专权十四年（打算法排挤将帅/隐匿边报/求和惯性）→ 1273 襄樊失守 → 1274 度宗崩、权威真空 → 1275 丁家洲大溃、贾似道倒台 → 1276 临安降。**"打赢了战役，输给了政治"是全书最苦涩的母题**（COURT_ANCHORS 已有）。

### 架空分岔点（书纲卷9-10）
主角保军制火种南渡 + 扶宋室（福州行在）→ 卷10 盐税养军、军医营、抚恤法。

### 重振六步（因果链，写进卷纲朝堂线）
1. **财政**：盐税+市舶（闽粤海贸）+军屯，摆脱会子通胀（咸淳财政崩溃教训）——卷10 已立，卷11-13 扩大
2. **军制**：募兵+军饷按时+抚恤法 → 将领不再依赖私兵/地方自筹 → 收拢吕氏残部/李庭芝系/张珏系/张世杰系
3. **中枢重建**：新法统（扶立宗室/幼主）+ 清算贾党余孽（范文虎等降将系）+ 清流入阁（文天祥系）——权斗四阶段"引爆-落定"在此
4. **边将联合**：蜀地（张珏-钓鱼城连线）、荆襄（吕文焕反正或对照）、两淮（李庭芝残部）、海路（张世杰）四线汇流（对应 DASONG_LIFECYCLE"三条战线汇流"）
5. **对蒙窗口**：忽必烈晚年（远征耗竭/财政崩溃/诸子争位/乃颜之乱）——反攻不靠神兵靠窗口（卷13-15 锚点已定）
6. **制度落定**：军权/财权/言路分立，不复制贾似道式相权（finale 蓝图"把胜果交给可持续制度"）

## 八、校验规则（人物级时代错位）

- 正文/细纲提到人物名时，章节年份 < 人物登场窗 → **时代错误（high）**："X 尚未登场（公元Y年登场）"
- 人物已卒（死亡年 < 章节年份）仍作为在场人物活动 → **时代错误（medium）**（提及追忆不拦）
- 皇帝名讳直呼（赵昀/赵禥）→ **避讳违规（medium）**（"官家/今上"替代）
