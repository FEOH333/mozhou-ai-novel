# V0.95.0 长程质量保持系统性重构方案

> 依据：四路深度审计（代码全量 / 提示词工艺 / 两书正文衰减实测 / 五外部框架盘点）+ 网文节奏工程与 arXiv 长篇连贯性调研。
> 目标：让《示例历史长篇》（已签约、26 章）写到 300 章不衰减——把「越写越差」从结构性必然变成可拦截、可自愈的工程问题。

## 一、诊断结论（审计实证）

### 1. 修仙书（弃书反面样本，125 章解剖）——「越写越差」是三段式断档，不是匀速下滑
| 拐点 | 位置 | 信号 | 机制根因 |
|---|---|---|---|
| 破折号失守 | ch22-24 起永久 | 1-21 章均值 6.9 → 末段稳定 30+（ρ=0.652） | 单章纪律无写前阻断、无跨章纪律失守信号 |
| 对话空心化 | ch43-76 谷底 | 连续 4 章对话占比 0% | 对话占比零防线 |
| 跨章复读爆发 | ch120-125 | 38 字逐字复现跨章、重叠率 0.064 | 长程记忆衰减 + 复读检测窗口仅 8 章 |

### 2. 实测书（26 章现状）
- 唯一单调抬头信号：动作母题密度（ρ=0.470，ch19-26 踩线「蹲下/转身」）——V0.94 防线恰好覆盖。
- 卷 2 短章 7 章 <2800 字（已知存量）。
- 其余信号（套话/议论/复读/超长段）全部健康，优于修仙同期 71%~74%。

### 3. 结构性风险（100-300 章必然放大，代码审计 P0）
1. **向量检索层闲置**：indexBook 仅手动 HTTP 触发；semanticSearch 只检 fact——章节正文/摘要向量从不进写作上下文，ch5 细节到 ch200 只能靠摘要碰运气。
2. **items/factions 零注入**：法宝/信物/势力在写作与审校上下文不可见——道具穿帮无防线。
3. **伏笔排序失真**：active() 按 importance 升序 slice(0,6)，新埋伏笔被老伏笔永久挤出。
4. **复读窗口固定 8 章** vs 指令「跨章不得复用前文比喻」的全书承诺。
5. **审校长篇退化**：伏笔/角色全量注入（100+ 条稀释注意力），且看不到滚动摘要/时间线/早期设定。
6. **滚动摘要双写漂移**：settle 追加 12 段 vs archive 覆盖结构化——无单一真源。

### 4. 提示词工艺缺口（Top 3）
- **F1 卷际张力升级完全缺失**：全书无一条「本卷冲突烈度/对手量级/代价面须高于上卷」——「越写越平」的结构性根源。
- **F2 卷内曲线坐标缺失**：写作不知道「本卷第 X/Y 章、距卷末高潮 N 章、当前相位」。
- **A1/A2/A3 写审脱节复发**：动作母题指令≤2 检测≥4；钩子强度三套阈值；禁词注入 40 检 106。

### 5. 外部框架引入（性价比排序后取舍）
引入：三章一轮批次自检（novel-writing-framework）、叙事记忆库 memory_entries（show-me-the-story）、卷级 Arc 压缩、角色语音卡+低谷分配表、爽点节奏调度+钩型轮换、写前阻断五问、中段疲劳检测。
不引入（留 P2）：Prompt Registry 全量拆分、GraphRAG、风格克隆集群、多 Agent 循环、引用式段落级修订（与现有重写闸门体系冲突）。

## 二、六大工程（实施清单）

### 工程一：长程记忆层（治「忘记」）
1.1 **叙事记忆库**：新表 `memory_entries{category(voice/promise/detail/scene/relation), chapter, content, source_scene}`；settle 后 LLM 提取（口头禅/承诺/道具细节/名场面/关系里程碑，≤6 条/章）；修订章删旧重提；预算裁剪（超 400 条 LLM 裁剪，降级保留最近）；写作按场景关键词+类别注入（voice 优先）；与向量检索互补（结构化保质感，语义召回保细节）。
1.2 **向量盘活**：settle 落库后增量索引新章（kind='chapter'，chunk→embedding→vectors，失败静默降级不阻断）；write 尾部 `semanticSearch(bookId, scene.beat+scene.location, 4, 'chapter')` 注入早期相关场景摘录；audit 同源注入。
1.3 **卷级 Arc 压缩**：volumes 加 `summary` 列；卷内全部完成时懒生成单段卷摘要（复用 summaries 聚合 + LLM 精炼，fail-closed 失败可重试）；归档注入升级为「卷速查表（每卷一行）+ 最近批次 rolling」；治 O(章) 注入膨胀。
1.4 **滚动摘要两段式统一**：settle 与 archive 写同一结构 `{recent:[最近K章增量段], pinned:[必保块]}`；formatRolling 兼容读旧格式；单一真源。
1.5 **items/factions 场景卡注入**：`itemCardsText(bookId, {names})` 仿 characterCardsText；细纲/正文提及实体时注入；settle touchItems 锚点推进 last_chapter。
1.6 **伏笔排序修复**：activeForeshadowsText 改「超期优先 + 最近埋设其次」（复用 prioritizeAuditHooks 范式），写审同源。

### 工程二：节奏引擎（治「匀速化/拖沓/平淡」）
2.1 **爽点三级调度**：schedulerCheck 增加「距上次中爽（payoff≥中）章距 >5」「连续平路（低强度+低回报）≥3 章」本地检测 → 强约束注入；对齐 3-5-10 法则与 top10% 作品 1.8 章/峰。
2.2 **钩型轮换确定性检测**：本地 `classifyEndingHook`（悬念/反转/情绪炸弹/信息投放/危机四型启发式）；连续同型 ≥3 章报 medium；写审同源（细纲钩型多样 + 审校核查）。
2.3 **场景节奏标注 pacing**：细纲 scenes 增加 `pacing`（铺垫/推进/爆发/余韵）；写作指令按 pacing 注入句长纪律（爆发段每句 ≤15 字短句加速，余韵段长句）；细纲质量门校验卷内 pacing 分布（爆发章禁连续缺席）。
2.4 **卷内曲线坐标**：写作/细纲指令注入「本卷第 X/Y 章，当前相位（铺垫/推进/收束），距卷末 N 章」+「卷高潮事件不得在卷前 1/3 透支」。
2.5 **卷际张力升级纪律**（ESCALATION_TEXT）：三轴升维检查单（对手量级/舞台层级/代价面至少一轴上移）；注入卷纲生成 + 卷审复核项。

### 工程三：反衰减纵深（治「断档式劣化」——修仙三拐点各设防线）
3.1 **纪律失守信号**：recovery.detectDrift 增加滑窗纪律信号——近 5 章破折号均值 >20 / 对话占比连续 3 章 <15% / 母题连续 3 章踩线 → 触发全局诊断（治 ch22 式「单章未超标但纪律已失守」）。
3.2 **对话占比防线**：rules.js `detectDialogueBalance`（对话行占比 <15% 或 >85% 报 medium，参与审校 verdict）；写审同源（写作指令对话占比 30-70% 区间要求，非纯对话章）。
3.3 **复读窗口扩展**：detectCrossChapterRepeats/Metaphors 比对源从「前 8 章」扩为「前 12 章 + 全部归档卡 key_details」双源；归档卡含早期金句细节，治「早期授权复用池」。
3.4 **三章一轮批次自检**：新 `batchScan.js`——每 3 章结算后聚合本地信号（破折号/母题/对话占比/钩型/套话/爽点密度）成批次报告；任一信号连续 3 章踩线 → 生成 high 约束注入后续写作（制度化 novel-writing-framework 三章一轮）。
3.5 **中段疲劳检测**：连续 5 章无新实体/新地点/新钩型 → recovery 信号（治 100-300 章中段疲软）。

### 工程四：写审同源批量校准（治「该拦没拦」）
4.1 动作母题阈值 ≥4 → ≥3 medium（对齐指令「≤2」）。
4.2 钩子强度统一：细纲 ≥3 / 正文 ≥3 / 快感审计 <3 无钩——三处同步一把尺。
4.3 禁词全量注入：styleRulesText slice(0,40) → 全量；AI_CLICHE_WORDS 补 12 漏词（闻言/苦笑/暗自/垂眸/怔了怔/愣了一下/心跳漏了一拍/点了点头/面无表情/颔首/眸色/暗暗），检测表自动同步。
4.4 场景字数双标准消除：minWords = max(700, round(target×0.65))。
4.5 system 铁律裁决句：「事件清单硬约束、呈现方式软约束」。
4.6 **写前阻断五问**：细纲质量门扩展——细纲必须声明 本章爽点（主谓宾+对方损失）/ 章末钩子类型与内容 / 冲突物理形态 / 开篇 300 字事件 / 上一卷对手量级对照，缺项驳回重生成（V0.94 质量门范式扩展）。
4.7 平台周期规则落 schedulerCheck（主角战斗章距/配角高光章距/死亡或重大损失章距）。
4.8 未结对禁令补正例与量化（C1 心理独白≤3 句/段、C2 世界观随事件带出、C3 卷末钩正例、C4 同型章≤2 连续；D1 张力量化、D3 升维检查单）。
4.9 情绪曲线指令兜底：写作指令常驻软规则（无快感数据时「本章至少一次情绪变化」）。
4.10 历史书风格画像打脸规则过滤（styleRulesText 对 isHistory 过滤冲突规则）。

### 工程五：台账治理（治「假欠债/真烂尾」）
5.1 伏笔/钩子 id 映射：foreshadows 加 `hook_desc_hash` 列，registerHooksFromOutline 建钩时回写映射；auditPleasure 兑现时按 hash 联动 foreshadows（消灭 desc 模糊匹配失步）。
5.2 钩子老化：长线钩（long/super）超期 >15 章且无推进 → 自动 expired 并转 foreshadows 主线锚点（pleasure 表只管期待节奏，foreshadows 管主线回收）。
5.3 conflicts 全局债清理：pruneBefore 补 chapter_id IS NULL 分支（全局债随章龄归档）。

### 工程六：结构整合
6.1 **量化红线单一来源**：新 `server/data/redlines.js`——AI 味词表（AI_CLICHES ∪ AI_CLICHE_WORDS）、破折号≤20、段落≤200、同词≤2、对话占比区间等全部常量；prompts/rules/creative_packs 统一 import（治五处维护漂移，V0.93.4/0.93.7 两次踩坑的根治）。
6.2 STYLE_PROFILES 内置代表作文本替换为自撰示范句（版权红线清偿）。
6.3 评审门 severity 注释映射统一（轻量：文档化映射表，不动 verdict 枚举）。

## 三、验收线
1. 每项先写失败测试再实现（tests/v140-v143）；全量回归全绿。
2. 实测书 26 章存量不回退：新检测器对存量章跑 dry-run 不产生误伤风暴（对话占比/钩型等新检测需用实测+修仙双书校准阈值）。
3. mock 模式全流程可跑（记忆提取/卷摘要/向量索引在 NOVEL_MOCK_LLM=1 与 embedding 不可用时全部降级不阻断）。
4. 版本收尾：git commit + AGENTS.md §0/§5/§8 同步 + 提醒重启 8770。

## 四、明确不做（记录理由，留 P2）
- Prompt Registry 全量拆分（高成本、收益是可维护性而非质量；6.1 红线单一来源已治最痛的漂移点）。
- 引用式段落级修订 blocks（与 applyValidatedChapterRewrite/applyValidatedSceneRewrite 闸门双轨风险）。
- GraphRAG / 风格克隆 / 多 Agent 循环（既定取舍不推翻）。
- attraction/pleasure_audit 门合并（动 pilot 主循环风险大；语义重复已在 4.2 统一阈值中缓解）。
