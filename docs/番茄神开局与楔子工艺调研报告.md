# 番茄神开局与远期楔子工艺调研报告

> V0.98.3 调研底稿。目的：回答"楔子功能能否写出神开局"，并把结论翻译成可量化、可本地校验的工艺文本。
> 调研日期：2026-08-22。来源分级：平台机制类为行业/社区观察（非官方证实，不写入平台事实库）；写作工艺类为作家经验总结。

## 一、平台机制观察（为什么第一屏是生死线）

- 番茄按书名/简介/标签推 500-1000 人测试，**首章读完率 >40% 才进下一轮**；前三章完读率过低则不再给量（知乎番茄爆款攻略、网文666 平台指南——行业观察，未经官方证实，只作创作侧参考，不进 `platform_guidance.js` 事实层）。
- 免费算法平台对节奏的要求显著快于起点/晋江：**前 300 字必须出冲突、500 字内见目标/阻碍、1000 字内首个爽点、章末留扣**。
- 番茄建议单章 2050-2300 字（利于有声转化）——与本项目"章 2000-6000 字"区间兼容，不另立标准。

**对本工具的含义**：楔子（chapter1_cold_open，200-700 字预算）承担的是"第一屏 300 字生死线"——它必须自己就是一场正在发生的高能事件，而不是气氛铺垫。第一章正文随后接住回切，两段合起来构成读者看到的第一屏+首章。

## 二、"神开局"工艺拆解（多来源交叉验证）

### 1. 楔子的本质：让读者先"偷看"高潮（故事革命《一开篇就直冲天际的5大写作手法》）
- 楔子=故事开始前的片段，目的是让读者**先看到高潮的一角**或故事如何发生，勾起继续阅读的欲望。
- 网文惯例：楔子讲前世恩怨/未来名场面，为正文制造悬念（知乎：楔子/引子/序章之辨）。
- 框架型楔子须与"尾声"呼应——对应本工具的读者契约兑现机制（`fulfillOpeningReaderContract`）。

### 2. 第一屏工艺（番茄爆款攻略/17K 创作中心/搜狐黄金三章指南）
- **开头单刀直入**：第一秒抓住眼球；"林家村四面环山，村头老槐树……"式背景介绍是标准毒点。
- **冲突具体到"谁在对谁做什么"**："局势紧张"不是冲突，"第二拨砲石压进膛口"才是。
- **主角在场且正在选择**：开篇聚焦主角，减少无关人物；读者追的是人不是历史课。
- **悬念手法**：倒叙法、疑问法、人物反常举动、戏剧性反讽（读者知道而角色不知道——正是远期楔子的结构优势）。
- **章末/段末在悬念中切断**。

### 3. 名场面开局范例（《白鹿原》等 30+ 开头拆解）
- "白嘉轩后来引以为豪壮的是一生里娶过七房女人"——悬念+名场面式：先给结果一角，扣住因果。
- 好开头奠定基调、叙事方式与语感；简洁明了、直接写人物和故事。

### 4. 历史文专属（中国作家网·月关谈历史小说"高级感"）
- 依托真实历史，以古人可以理解和接受的方式展开；避免史料堆砌。
- 远期楔子天然合规：目标事件是真实史实（1259 钓鱼城），主角在场方式受作者锁约束（不得发明亲手击杀蒙哥等）。

## 三、落地（写审同源，注入候选写作/审校/压缩三处指令）

`server/data/literary_techniques.js` 的 `COLD_OPEN_CRAFT_TEXT` 为八条量化纪律（V0.98.3 七条，V0.98.12 新增"镜头贴人·人声在场"并强化主角点名）：

| 工艺 | 量化边界 | 本地裁决 |
|---|---|---|
| 前三句有事发生 | 年份/地名/人名定位现场 | 第一屏 120 字内必须出现事件信号词（`cold_open_first_screen_unanchored`） |
| 冲突具体 | 120 字内出现"谁对谁做什么" | 审校判定 |
| 主角点名在场 | 主角姓名第一屏 120 字内出场并行动；空镜≤1 句 | **本地判废（V0.98.12 新增 `cold_open_protagonist_absent`）**——此前仅审校软判，免费模型屡漏"纪录片念稿"开场 |
| 信息差悬念 | 结果一角+扣因果，禁旁白套话 | 审校判定（AI 味词表已有） |
| 代价可见 | 具体的人/物，禁成语套话 | 审校判定 |
| 回切即钩子 | 真实年差一句收束 | 尾部 180 字定位检查（已有） |
| 节奏体量 | 段≤150 字、1-3 句为主 | 预算 300-800 字（V0.98.3 从 200-700 上调） |
| 镜头贴人·人声在场 | 每节拍由主角触发/承受；至少一个具体的人开口 | 审校判定 + 契约块显式注入 |
