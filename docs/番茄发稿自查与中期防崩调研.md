# 番茄发稿自查与中期防崩调研

> V0.105.0 调研底稿。目的：把作家课堂两篇工艺文翻译成本工具的占用轴、本地愈合与细纲硬闸，而不是每章灌一张文学考卷。
> 调研日期：2026-09-02。来源分级：官方创作指导（不是审核阈值），写入 `platform_guidance.js` 的 `officialCreativeGuidance`（R31/R32）。

## 一、来源

1. [告别低级失误：发稿前必做的四步自查](https://fanqienovel.com/writer/zone/article/7672343903181226008)（2026-08-24）→ R31
2. [告别中期疲软：长篇防崩文自救指南](https://fanqienovel.com/writer/zone/article/7673406206286757950)（2026-08-31）→ R32

## 二、文 1 发稿自查（人物 / 语言排版 / 句式 / 章节边界）

可本地判定、值得进工具的形态：

| 课内问题 | 本工具落地 | 层 |
|---|---|---|
| 开篇人名轰炸 | 花名册名在前 200 非空白字 unique > 4 记占用 | L0，无花名册不报 |
| 新人无身份 | 首次出场附近无关系/职分标记记占用 | L0/L2 |
| 相邻句双人心想 | ≥2 个主语 + 心想/心道/暗想 → `proseFix` | L2 |
| 因此/于是/所以堆砌 | 同词 ≥3 本地删第 3 次起 | L1 |
| 连续长句 | 连续 ≥3 句且每句 ≥40 字记占用 | L0/L2 |
| 阶梯碎段假排版 | 连续 ≥4 段、每段 ≤8 字、非对白 → 合成一段 | L1 |
| 一段两人说话 | 同段 ≥2 处引号且 ≥2 个说/道/问 → 插换行 | L1 |
| 「不是 X 而是 Y」 | 已有 `detectNotButPattern`，不重复造闸 | 既有 |
| 章末赶路空镜 | 末段含赶路/天色/柳树等且无？！与引号；占用只看近一章 | L0；修订 `craftRegression` 拒收 |

课内「每章收在情节节点」三点打中一点即可，不是每章考三点全中。未占用轴提示词一个字不提。

## 三、文 2 中期防崩（阶段 / 四要素 / 四表 / 复盘 / 换冲突）

| 课内问题 | 本工具落地 | 层 |
|---|---|---|
| 5–10 章一个阶段、每章 1 个小任务 | 从已有卷纲编译阶段窗，不新开阶段细纲 LLM | L0 |
| 关卡签名重复 | 3-gram Jaccard ≥0.10 → `OUTLINE_STAGE_TASK_REPEATED` | L3 仅细纲 |
| 四要素（goal/conflict/turn/reader_pull） | **四条全空**才 `OUTLINE_FOUR_ELEMENT_VOID`；缺一条不 hard | L3 |
| 副本换冲突核心 | 只在阶段起点比较 `conflict_focus` | L3 |
| 写前四表 | 提及才注入、条数封顶（人 4 / 时 6 / 伏 4） | L0 |
| 伏笔无锚点 | 有 `chapterText` 时无逐字 quote 则 `isolated`，不新建 | 结算 |
| 10–20 万字复盘不回头大修 | `midStoryReview` 每 10 完成章 **或** 跨 10 万字，同一关只跑一次；指令写「不要修改已写章节」 | 既有任务 |

「每章 1 个小任务」不是短章许可。阶段 3–9 个互不重复关卡，场景仍须层层新信息，字数下限不变。

问题 5（人物不立体）官方课自身锁定为作者功力，本轮不做。

## 四、软硬分层（吸取 V0.103 同构考卷）

每章把课全文和断簪正例灌进指令，会把合格章收束成最不易被检出的写法，并让单一模型跟不全、幻觉、卡章、烧 token。

```
L0 占用编译器（零 LLM）：近窗未犯过的毛病不提
L1 形态本地愈（零 LLM）：插换行 / 合并碎段 / 删超额连接词，复检归零
L2 文学软项：proseFix + 最多一轮命中修订；预算耗尽 defer，不清场
L3 结构硬闸只在细纲：四要素全空 / 关卡签名重复 / 阶段起点冲突焦点重复
```

不新增 `prepublish_check` / `stage_outline_llm` 任务。中期审阅复用既有 `mid_story_review`。

## 五、写审同源与文件

- 阈值：`server/data/redlines.js`（`nameBombUniqueMax` / `connectorDetectMedium` / `midStoryWordGate` 等）
- 纪律真源：`PREPUBLISH_CRAFT_TEXT`（检测/边界用，禁止每章整段注入）
- 占用与愈合：`server/engine/craft_occupancy.js`
- 阶段窗：`server/engine/stage_window.js`
- 写场/审校/修订 L4 只点名已占用项；`healCraftMorphology` 在 `writeScene` 与 `reviseScene` 落库前执行
- 返工文风闸（`validateRecoveryProseImprovement`）不计占用轴 `axis`，避免旧稿多一项、候选同构不过闸
