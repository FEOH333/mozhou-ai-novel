# 章卷命名工艺调研报告（V0.107.0 前置调研）

> 调研目的：用户反馈「章卷起名太单调无聊」。本报告拆解高质量历史类小说的章名/卷名命名艺术，提炼可工程化的纪律与检测规则，供 `TITLE_CRAFT_TEXT`（纪律文本）与 `titleShapeOf`（句式族检测）落地。
> 版权红线：所引书名/章名仅作调研说明，纪律文本全部自撰，不建库存正例句库。

## 一、标杆作品章名风格拆解

| 作品 | 章名形式 | 风格特征 | 可借鉴点 |
|---|---|---|---|
| 《新宋》（阿越） | 四字格为主（声名鹊起/终南捷径/牛刀小试/执拗相公） | 典雅规整，史家气质 | 四字格的信息密度与端正感 |
| 《宰执天下》（cuslaa） | 七言诗句式（一年穷处已残冬），卷名四字格（塞上枕戈） | 古典章回味最浓 | 卷名与章名的长度分层；诗句化长章名的韵味 |
| 《绍宋》（榴弹怕水） | 长短句混用、口语化（明道宫/赤心队/朕的心腹都在哪里？/绝杀） | 极简跳跃、网感强 | 问句/悬念章名的钩力；**用典门槛控制**（诗词不超中小学课本范围，靠正文引用制造震撼点而非堆在章名里） |
| 《大秦帝国》（孙皓晖） | 四字意象史诗格（黑色裂变/金戈铁马/铁血文明/万古国殇） | 悲壮辽阔 | 卷名的意象史诗格——从时代命运取象而非事件流水 |
| 《大明王朝1566》（刘和平） | 无章名（纯数字编号） | 出版向、剧本式 | **反面参考**：网文平台需要章名钩，不可学 |

## 二、章名句式族分类学（工程化）

从上述作品提炼六族（本地可判定，按长度带+标点+数字）：

1. **极简名词族**（2-3 字）：绍宋「明道宫」「会议」——冲击力强但连排即单调（本书现状「军报」「夜哨」「斥候」即此族过度使用）。
2. **四字格族**（4 字，名词性/成语式）：新宋全系、大秦卷名——典雅端正，信息密度高。
3. **动宾/主谓族**（含明显动作结构）：「绝杀」「夺册」——动感强，事件预告。
4. **长句族**（7-10 字）：宰执七言诗、绍宋口语长句——韵味/悬念承载最大。
5. **问句族**（含？）：绍宋「朕的心腹都在哪里？」——钩力最强，稀用。
6. **数字族**（含汉字/阿拉伯数字）：「十人一绳」「三人成虎」——具体可数，规模感。

## 三、章名的功能分类

- **悬念钩**（问句/半遮）：点出冲突不点出结果——平台追读价值最高。
- **意象定调**（四字格/名词）：为全章定情绪底色。
- **事件预告**（动宾）：预告关键事件——**必须兑现**，否则即「章名与内容牛头不对马嘴」。
- **人物聚焦/反讽/留白**：稀用调味。

## 四、平台视角（番茄）

- 章节读完率/追读率直接决定推流；章名「成事不足、败事有余」——好章名未必加分，烂章名必然减分。
- 情绪驱动：有限字数里引起读者情绪（激昂/压迫/好奇）。
- **公式必须轮换**：连续三五章同一种公式（如全是悬念型）读者会疲劳；写完前 30 章应把章名连起来读一遍自查。
- 有故事感、画面感，言简意赅；推荐位标题 15-30 字（章名可参考但不必照搬）。

## 五、卷名与章名的区别

- 卷名更**抽象、意象化**：从本卷的核心转折/时代命运/主导意象取材（大秦「黑色裂变」= 商鞅变法的时代质感），不剧透结局，不写事件流水账。
- 卷名长度独立于章名（大秦卷名四字、宰执卷名四字、本书既有好卷名《弦纹》《天倾石坠》《算筹断翅》皆 3-4 字意象格）。
- 章名服务单章钩力与兑现；卷名服务整体气质与记忆点。

## 六、工程化规则提炼（纪律文本依据）

### 写入 TITLE_CRAFT_TEXT 的纪律（写审同源）

1. **句式族轮换**：近 3 章不得同为一句式族；全卷单一族占比 ≤60%。六族混用，钩力型（问句/悬念）稀用点缀。
2. **长度带**：3-10 字，以 4-8 为主；允许少量 2-3 字极简与 7-10 字长句调剂。
3. **半遮不剧透**：章名点出冲突/意象/悬念，不写出结果；「谁+做什么」留一半。
4. **意象承载**：名词不直给事件时，须是本章在场意象（物件/天气/地点/身体感），起名前确认本章有这个意象的落点。
5. **历史题材**：可用文言质感、典故、时代意象（年号/官职/器物/地名），用典门槛控制——只用中小学课本级典故，不炫考据。
6. **卷名工艺**：意象化 2-6 字，从本卷核心转折/主导意象/时代命运取材；禁止事件流水账式卷名（「XX之战」「XX风云」）；不剧透结局；与已用卷名不同韵脚重复。

### 本地可判定检测（rules.js）

1. `titleShapeOf(title)`：六族分类（长度带+？+数字+动词性结构黑名单近似判定）。
2. `titleShapeStreakIssues(titles)`：连续 ≥3 同族硬报；单族占比 >70% 软报。
3. `chapterTitleDeliveryIssues(title, text)`：
   - **事件承诺型**：标题命中事件词族表（TITLE_EVENT_LEXICON）且正文词族零在场 → high+proseFix（ch52「帝星陨落」正文零着墨即此类事故）；
   - **具象型**：连续 CJK bigram 全部零命中 → medium+proseFix；
   - **意象型**：抽象意象豁免，low 只提示（保文学命名自由——《故园成灰》合法）。

### 既有资产复用

- `alignment.js` AI_FLAT_TITLES（动作直述黑名单）继续拦截「夜探/夜袭」式直给；
- `adjustChapterTitle` LLM 改名 + 本地校验（长度/章号残留/重名）已存在，补 outline_json.title 同步与已发布边界保护；
- `detectTitleGap`（bigram 兑现）升级为 chapterTitleDeliveryIssues 的具象型分支。
